# Informe de Exposiciones - II Corte

Informe individual de las exposiciones realizadas durante el II corte de la asignatura **Aplicaciones Distribuidas (ISR-701)**.

**Autor:** Fredy Vladimir Farinango

## Contenido

El documento evalúa, por cada integrante de los equipos expuestos, los siguientes aspectos:

- Tiempo expuesto (estimado)
- Claridad de lo expuesto
- Coherencia del contenido
- Profundidad con la que se amplió el tema
- Si se abordó la implementación de la aplicación
- Resumen de lo expuesto

## Equipos evaluados

- Equipo ACC — Sistema de Soporte Técnico ISP
- Equipo TiendaTech
- Equipo SGA — Escuela "Provincias Unidas"
